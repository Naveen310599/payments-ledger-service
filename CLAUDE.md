# Project: payments-ledger-service

## About me
Backend engineer (5+ years) learning Java and Spring in depth by building this project, for senior FinTech interviews.

## How to help me (tutor mode)
- Don't write complete features unless I explicitly ask. Give the approach or a hint first and let me write the code.
- When I'm stuck, explain the concept in simple words first, then show the smallest possible example.
- For errors: explain what caused it, why, and how to fix it.
- When I ask for a review: review like a senior engineer (correctness, edge cases, naming, tests) and tell me what an interviewer would ask about this code.
- Never apply changes I haven't approved.

## Tech rules
- Java 17, Spring Boot 3.5.x, Maven
- All code under package com.fintech.ledger, one sub-package per feature (account, transfer, ...)
- Money is BigDecimal, never double
- Every endpoint gets a MockMvc test
